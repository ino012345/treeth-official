作成日: 2026年9月23日

## 設計の全体方針

**Before**: Creative Agency Portfolio（作品として美しい）
**After**: High-end Creative Agency + High-conversion Business Website（美しく、かつ依頼したくなる）

維持するもの: ダーク／モノクローム基調・洗練されたタイポグラフィ・大きな余白・大型ビジュアル・Modern/Premium・テクノロジー感
変えるもの: **スクロールを演出の再生時間として消費する構造**と、**抽象的で検証不能なコピー**

## 1. Hero

### Current
- `height: 400vh`（モバイル300vh）のセクション内で、111枚のcanvasフレームをスクロール進捗に連動再生
- h1 = `Ignite the Digital Core.`（英語のみ）
- 説明文 =「ビジネスの核となる、圧倒的なデジタル体験を。妥協なき美しさと…次の次元へ引き上げます。」
- CTA =「無料相談を予約する」
- ローディングオーバーレイ（全画面・フレーム読込待ち）

### Problem
| # | 問題 | 重大度 |
|---|---|---|
| 1 | サービス説明に到達するまで**デスクトップ4画面**のスクロールが必要 | Critical |
| 2 | h1が業種を説明せず、3秒で「自分向けか」を判断できない | Critical |
| 3 | NN/gが最悪と指摘する「テキスト＋スクロール改変」の組み合わせ | Critical |
| 4 | モバイルで同じ構造（NN/gは明確に非推奨） | Critical |
| 5 | Heroフレームだけで13MB | High |
| 6 | 初回に全画面ローディングが出る（コンテンツが何も見えない時間が発生） | High |
| 7 | CTAラベル「予約」と遷移先（フォーム）が不一致 | Medium |

### New Design
- **高さを `min-height: 100svh` の1画面に変更**。通常スクロールで直下のサービスセクションへ到達。
- 背景は **Heroフレームの1枚（frame_0060.webp / 約120KB）を静的表示**。`next/image` + `priority` でLCP要素として正しく読み込む。
- ブランドの動きは **CSSによる超低速アンビエント・ズーム（40秒周期・scale 1.0→1.06）** で維持。スクロールとは完全に独立。
- **h1を日本語に変更**（下記コピー案）。`Ignite the Digital Core.` は h1 の上に**ブランドコピーとして小さく残す**（情報伝達の主役から外すが、ブランドは捨てない）。
- CTAを2つに: 主「無料で相談する」/ 副「制作実績を見る」。
- CTA直下に microcopy:「まだ内容が固まっていなくても大丈夫です。」（実態として確認できる範囲のみ）
- **信頼バッジをファーストビュー内に配置**: 実績45件 / 評価5.0（Coconala公開情報で検証済）
- **全画面ローディングオーバーレイを撤廃**（静的画像になるため不要）

### UX Rationale
- NN/g: 目的志向ユーザーはscrolljackingに最も不寛容。TREETHの見込み客はまさにこの層。
- Information scent: 「何の会社か」が最初の視界に必要。
- WCAG 2.3.3: スクロール連動モーションの撤廃により根本的に解消。
- LCP: 静的画像＋priorityの方が、JSでImage()を111個生成するより構造的に速く安定する。

### Expected Impact
- サービス理解までのスクロール: **4画面 → 0画面**（ファーストビュー内で完結）
- Heroの転送量: **13MB → 約120KB**
- 直帰率の低下 / 「何の会社か分からない」離脱の解消

## 2. Projects（最重要）

### Current
- `height: 500vh`（モバイル300vh）
- スクロール進捗 0.04〜0.78 に5案件を割り当て、**ユーザー操作なしに自動で表示・非表示**
- 背景は111枚のトンネル映像canvas
- 同時に見えるのは常に1件

### Problem
| # | 問題 | 重大度 |
|---|---|---|
| 1 | **比較できない**（常に1件のみ表示） | Critical |
| 2 | 見たい案件を選べない / 戻るのが困難 | Critical |
| 3 | **キーボードで到達不能**（Tab順に一度も現れない・WCAG 2.1.1違反） | Critical |
| 4 | 通過に**デスクトップ10.13画面**分のスクロール | Critical |
| 5 | 読み終わる前に次へ進む / 止まると消える | High |
| 6 | トンネルフレーム4.5MB | High |
| 7 | 「TREETHが何を担当したか」が不明 | Medium |

### New Design — Editorial Portfolio Grid
- スクロール連動 / canvas / 500vh を**全面撤廃**。通常フローのセクション（約1.5画面）へ。
- **Desktop**: 1件目を全幅のフィーチャー枠、残り4件を2カラム（視覚的リズムのあるエディトリアル構成）
- **Mobile**: 1カラム
- 各カード: 大きなスクリーンショット（next/image）/ 案件名 / サイト種別 / 業種・目的 / **TREETH担当範囲**
- モーション（控えめ）: hover時に画像 `scale(1.04)` + 矢印がわずかに移動。**モバイルはhover非依存**で情報が常に見える設計。
- カード全体を `<article>` でマークアップし、見出し階層を維持。

### UX Rationale
- ユーザーの目的は「鑑賞」ではなく「**比較**して自分の案件に近いものを探す」。グリッドは構造的にこの目的に合致。
- 2026年のエディトリアルレイアウト潮流とも一致するが、**採用理由はトレンドではなく目的適合**。
- DOM順に存在することでキーボード・スクリーンリーダーから到達可能になる。

### Expected Impact
- 実績通過のスクロール: **10.13画面 → 約1.5画面**
- 5件を**同時に比較可能**
- キーボード利用者が実績にアクセス可能（Critical a11y解消）
- 転送量: **4.5MB削減**

### Current → New

| 箇所 | Current | New | 理由 |
|---|---|---|---|
| Hero h1 | Ignite the Digital Core. | **店舗・企業のホームページを、<br>成果につながる形で。** | 業種と対象が3秒で伝わる |
| Hero 説明 | 圧倒的なデジタル体験を…次の次元へ引き上げます | コーポレートサイト・LPを、企画からデザイン・実装・公開まで一貫して制作します。Web制作が初めての方でもご相談いただけます。 | 具体・対象の明示 |
| Hero CTA | 無料相談を予約する | 無料で相談する | 遷移先（フォーム）と一致 |
| Bento | 圧倒的なパフォーマンス | 表示が速く、検索にも配慮 | 検証可能な記述へ |
| Bento | 妥協のないピクセルパーフェクトなデザイン | 細部まで整えたデザイン | 誇張の削減 |
| Bento | 最新の技術スタック | 公開後も安心して使える技術 | 技術→顧客メリット |
| Bento | ビジネスの成果を最大化 | （削除・具体記述へ置換） | 検証不能な約束 |
| Testimonials | 圧倒的なクオリティと戦略的な設計で、確かな変革をもたらしてきました | 実際にご依頼いただいた方からの声と、これまでの実績をご紹介します。 | 誇張の削減 |

**顧客の声（TESTIMONIALS本文）は実際にいただいた文章のため一切改変しない。**

### UX Rationale
「圧倒的」「妥協なき」は発注検討者にとって判断材料にならず、むしろ警戒される。具体的な事実の記述に置き換えることで「安心して相談できそう」へトーンを移す。

## 4. Trust / Social Proof

### Current
- Coconalaリンクあり、顧客の声2件、実績5件（到達しにくい）
- 統計行は「5.0 / 5.0」「Strategic」「Seamless」= 後2つは形容詞で裏付けにならない

### New Design
- **`src/lib/site.ts` に検証済みの事実のみを定数化**（1箇所で更新可能・runtime scrapingは行わない）
  - `deliveredProjects: 45` — Coconala公開プロフィールの販売実績（2026年9月23日確認）
  - `rating: "5.0"` — 同プロフィールの評価
  - `certifications` — 情報処理安全確保支援士 / 応用情報技術者 / 個人情報保護士 / ITパスポート
- Heroファーストビューに「実績45件」「評価5.0」を配置
- 有資格を「セキュリティに配慮した設計」の**根拠**としてBentoで提示

**捏造しないもの**: 成果数値（CV率・売上等）、顧客名の追加、対応時間、料金。

### 事業者表現について — **Decision Required**
- Footer は「Web制作チーム」、特商法ページは「個人事業」、metaは「Webクリエイター」で不整合。
- Coconala公開プロフィールは個人名義。
- **本実装では、実態を断定しない中立表現**（「店舗・企業向けのコーポレートサイト・LP制作を行っています」）に変更し、サイトオーナーの確認を仰ぐ。

## 5. Process

### Current
Strategy & Planning / Design & Development / Testing & Launch（制作者目線の工程名・3ステップ）

### Problem
ユーザーが知りたいのは工程名ではなく「**問い合わせたら何が起きるのか**」。初めて依頼する人の不安が解消されない。

### New Design
依頼者目線の6ステップへ再構成:
1. **ご相談** — フォームから送信（内容が固まっていなくてもOK）
2. **ヒアリング・ご提案** — 要望を伺い、構成と見積もりを提示
3. **デザイン・制作** — 進捗を共有しながら制作
4. **ご確認・修正** — 実際の画面を見ながら調整
5. **公開** — 公開作業まで代行
6. **公開後のサポート** — 公開後の修正・更新に対応

### UX Rationale
Processセクションを「営業資料」ではなく「**安心材料**」として機能させる。FAQと役割が補完関係になる。

### Expected Impact
問い合わせ前の不安（何を準備すべきか・どう進むか）を事前に解消し、フォーム到達率を上げる。

## 6. CTA / Contact

### Current
- Hero CTA「無料相談を予約する」（遷移先と不一致）
- フォーム3項目（構成は最適）
- 送信前の不安に対するケアなし

### New Design
- CTAラベルを実動作と一致させる（「無料で相談する」）
- **フォーム項目は3項目のまま変更しない**（NN/g・Baymardの知見上すでに最適）
- フォーム上部に不安を下げるmicrocopy:「まだ内容が固まっていなくても問題ありません。『こんなサイトを作りたい』程度からご相談いただけます。」
- 必須表記を「※必須」から、Baymardの知見に沿って**明確なラベル**へ整理
- フォーカスリングを全インタラクティブ要素で可視化

### UX Rationale
Baymard: 67%のユーザーが「ためらう瞬間」に離脱する。項目数ではなく**心理的障壁**が残された課題。

### 禁止事項の遵守
返信時間・対応時間・料金は**実態が確認できないため記載しない**。

## 7. Accessibility

| 対応 | 内容 |
|---|---|
| WCAG 2.1.1 | Projectsグリッド化によりキーボード到達可能に |
| WCAG 2.3.3 | `prefers-reduced-motion: reduce` で Level 2/3 モーションを全停止。Lenisスムーススクロールも無効化 |
| WCAG 1.4.3 | zinc-500→zinc-400 / zinc-600→zinc-400 / white-30,40 の置換 |
| WCAG 2.4.1 | skip-to-contentリンクを追加 |
| WCAG 1.1.1 | 装飾画像に `aria-hidden` / 実績画像に意味のあるalt |
| 1.3.1 | h1→h2→h3 階層維持（現状も適切） |

**モーション階層**
- Level 1（理解に必要）: FAQ開閉・フォーム状態 → reduced-motion時も維持（時間短縮のみ）
- Level 2（ブランド体験）: entrance reveal・マグネティックホバー → reduced-motion時は無効
- Level 3（装飾）: アンビエントズーム・マーキー → reduced-motion時は完全停止
