# 事業者の氏名・住所の請求への対応手順（内部）

/privacy の C-3 で「運営者の氏名および住所は、ご請求があった場合に遅滞なくお知らせします」と表示している（案1、2026-11-16 にユーザーが承認）。この文書は、その約束を守るための手順である。

- 根拠: 個人情報保護法第32条第1項。個人情報保護委員会のガイドライン（通則編）3-8-1 では、「本人の知り得る状態」に「本人の求めに応じて遅滞なく回答する場合」も含まれる
- 運営者の氏名・住所は、このリポジトリ・ページ・メタデータ・JSON-LD・公開される環境変数のどこにも書かない。回答はメールで個別に行う
- 屋号「TREETH」だけで「氏名又は名称」として足りるかは確認していない。そのため、請求があれば氏名と住所の両方を回答する

## 受付

1. 窓口は contact@treeth.net とお問い合わせフォーム（C-2）
2. 請求の対象を確認する。氏名・住所のほか、ほかの第32条の事項（利用目的・開示等の手続・安全管理措置・苦情の申出先）を求められた場合も、同じ手順で回答する
3. 受付日をメモする

## 回答

1. **遅滞なく**回答する。目安は受付から2営業日以内
2. 回答するもの:
   - 個人情報取扱事業者としての運営者の氏名
   - 住所
3. 必要なら、ほかの第32条の事項も回答する（/privacy の該当箇所を示す）
4. 回答は請求者のメールアドレスへ送る。本人確認は不要（第32条の事項は、本人であれば誰でも知り得る状態に置く事項のため）
5. いたずらや大量の請求が疑われる場合も、まずは個人情報保護委員会のガイドラインに沿って対応する。断る場合は理由を記録する

## 記録

- 受付日・回答日・回答した事項だけを記録する（請求者の個人情報は、対応後に必要な期間を過ぎたら削除する）
- 回答を遅らせた場合は、その理由を記録する

## 見直し

- 屋号での表示で足りるかを専門家・個人情報保護委員会に確認した場合は、結果をこの文書と /privacy の C-3 に反映する
- 運営者の住所が変わった場合は、回答に使う情報を更新する（この文書には書かない）
